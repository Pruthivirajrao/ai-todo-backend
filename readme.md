AI-Powered Todo Application

The project is being developed step-by-step to understand how a real-world full-stack application is structured.

📦 Backend Installations
Production Dependencies
Install the main backend packages:
npm install express mongoose bcryptjs jsonwebtoken cookie-parser cors morgan dotenv zod
What each package does
Package	Purpose
express	Creates the backend REST API
mongoose	Connects Node.js to MongoDB and provides schemas/models
bcryptjs	Hashes and verifies passwords
jsonwebtoken	Creates and verifies JWT tokens
cookie-parser	Reads cookies from requests
cors	Allows frontend/backend communication
morgan	Logs HTTP requests
dotenv	Loads environment variables from .env
zod	Validates request data


🧑‍💻 Backend TypeScript Installations
Install TypeScript and development tools:
npm install -D typescript ts-node ts-node-dev
Type Definitions
Install TypeScript definitions for packages that need them:
npm install -D @types/node @types/express @types/jsonwebtoken @types/cookie-parser @types/cors @types/morgan
Note: bcryptjs includes its own TypeScript types in current versions, so @types/bcryptjs is not required.

⚠️ Important TypeScript Version
The project uses:
TypeScript 5.9.3
ts-node 10.9.2
ts-node-dev 2.0.0
Install these exact development versions:
npm install -D typescript@5.9.3 ts-node@10.9.2 ts-node-dev@2.0.0
Why?
An incompatible TypeScript version can cause errors such as:
TypeError: Cannot read properties of undefined (reading 'fileExists')
This happened when TypeScript 7.x was used with the older ts-node/ts-node-dev versions.
⚙️ TypeScript Configuration
tsconfig.json:
{
  "compilerOptions": {
    "target": "ES2020",
    "module": "commonjs",
    "rootDir": "./src",
    "outDir": "./dist",
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true,
    "forceConsistentCasingInFileNames": true
  }
}
Important options
Option	Purpose
target	JavaScript version generated by TypeScript
module	Module system used by Node
rootDir	Source code directory
outDir	Compiled JavaScript directory
strict	Enables strict TypeScript checking
esModuleInterop	Makes CommonJS/ES module imports easier
skipLibCheck	Skips checking declaration files
forceConsistentCasingInFileNames	Prevents casing-related import issues

const connectDatabase = async (): Promise<void> => {
  try {
    await mongoose.connect(process.env.MONGO_URI as string)

  } catch (error) {
    console.error("MongoDB connection failed:", error)
    process.exit(1)
  }
}

export default connectDatabase

🔒 Security Rules
Important security principles:
- Never expose the JWT secret to the frontend.
- Never expose the OpenAI API key to the frontend.
- Passwords must never be stored as plain text.
- Use bcrypt password hashing.
- Use HTTP-only cookies for authentication.
- Validate incoming requests with Zod.
- Users can access only their own Todos.
- Keep .env out of Git.
- Validate AI-generated data before saving it to MongoDB.
- Use centralized error handling.
